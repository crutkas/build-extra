# Git for Windows ARM64 payload architecture baseline.
#
# Every native PE in the ARM64 payload whose COFF machine is not
# IMAGE_FILE_MACHINE_ARM64 (0xAA64) is listed here. This is the residual x64/x86
# emulation debt, seeded from the ARM64 RTM packaging audit of v2.55.0.4.
#
# check-payload-architecture.sh fails when a shipped binary is not ARM64 and is
# absent from this file, and when this file grows beyond seed-entries. The list
# may only shrink; reductions are reported so progress stays measurable.
#
# Managed, architecture-neutral assemblies do not belong here. They are listed
# in arm64-payload-exceptions.txt, which refuses native machine types.
#
# Body format: one entry per line, "<machine><TAB><path>", sorted with LC_ALL=C.
# sha256 covers the body only: every non-comment line, LF-terminated.
#

# seed-entries: 433
# entries: 433
